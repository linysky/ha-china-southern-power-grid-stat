档位电价 = 当月账单反解出的实际电价，同一档位内固定不变；跨档当天显示按电量加权的混合价。实算单价 = 电费 ÷ 电量，因电费按「分」记账会有 ±0.0005 左右的微小抖动，属正常现象。账单 0 元的月份档位电价与实算单价显示为「—」（电费真值为 0），电量仍为真实值。

说明：南网已下线每日电费接口，页面中的每日电费按「当日电量所落的阶梯档」计价，第一档基准价由官方账单反解，每月合计精确等于南网账单真实值；跨档月份月末单价会高于月初。按分记账产生的尾差已分摊到各天，不再集中于月末。历史每日电量查不到的月份按账单均摊，并以橙色标注。账单电费为 0 的月份（预缴抵扣 / 未出账）电费按账单真值 0 显示，用电量仍按南网真实每日电量显示，来源标记 zb/zm；若日后电网补出正式账单，该月会自动重新计价。历史数据永久保留、只增不删。
